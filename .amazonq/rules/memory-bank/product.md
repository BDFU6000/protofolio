# Product Overview

## Project Purpose
A personal developer portfolio web/mobile application built with Flutter, showcasing the work, skills, experience, and services of Abd Almoneeb Abusetta — a Flutter/Dart developer with a focus on healthcare and product-development projects.

## Value Proposition
- Presents professional identity, projects, and capabilities in a polished, interactive single-page application
- Bilingual (English/Arabic) with full RTL support for Arabic-speaking audiences
- Dark/light theme toggle for user preference
- Responsive across mobile, tablet, and desktop viewports
- Downloadable CV generation via PDF export

## Key Features
- **Hero Section**: Introduction, profile image, animated entrance, CTA buttons (View Work, Download CV)
- **Projects Section**: Carousel/grid of project cards with detail drill-down screen per project
- **About Section**: Personal background, roadmap image, contact CTA
- **Experience Section**: Timeline of professional experience
- **Services Section**: Offered services display
- **Skills Section**: Technology stack with logos
- **Contact Section**: Social links, email, and inquiry form
- **Navigation Bar**: Sticky top nav with active-section tracking and mobile drawer
- **Language Toggle**: EN ↔ عربي switch in navbar and drawer
- **Theme Toggle**: Dark/light mode switch
- **CV Download**: PDF generation and printing via `pdf` + `printing` packages

## Target Users
- Potential employers and clients reviewing the developer's background
- Collaborators or partners evaluating technical fit
- Arabic and English-speaking professional audiences

## Projects Showcased
1. Smart Clinic — Multi-tenant healthcare ERP (Flutter, Supabase)
2. Sidaliti — Independent mobile product concept
3. Doctor Leandek — Connected healthcare ecosystem (Flutter, Supabase, Firebase, Google Maps)
4. Smart Clinic AI Assistant — AI layer for clinic management
5. Business Lead Generation Pipeline — Python/AI data pipeline
6. Libyan Arabic AI Voice Research — Speech model fine-tuning research
7. Tamayoz Al-Da'em Corporate Website — Bilingual corporate site (Figma, Vercel)
